# 俄语撰写规范

> 本项目所有俄语内容（页面、产品描述、博客）必须遵守本规范。核心目标：**杜绝机翻味**。

## 核心原则

**短到来不及发现是 AI 写的。** 上游 puerhdirect.com 的俄语之所以被客户评价为"自然"，不是翻译水平高，而是每条俄语不超过两句话，短到不暴露任何翻译痕迹。

## 句式铁律

| 规则 | 正确（上游风格） | 错误（机翻风格） |
|------|----------------|----------------|
| **每句 ≤ 10 词** | `Выбор сырья и формата через Telegram.` | `Обсуждаем ваши бизнес-цели, бюджет, вкусовой профиль и целевую аудиторию.` |
| **每段 ≤ 2 句** | `Завод в Мэнхай с 2006 года. Без посредников.` | 一段超过 3 句话，堆砌数据（500 м², 20-25°C, 65-75%...） |
| **名词结构优先** | `Отправка тестовых образцов в РФ.` | `Изготавливаем и отправляем образцы на утверждение.` |
| **避免动词变位链** | `Прессовка в Юньнани, упаковка в Фанцунь.` | `Запускаем производство, прессуем, упаковываем, контролируем качество.` |
| **一句话一个信息** | `Прямые закупки в Юньнани.` | `Поставки пуэра с контролем качества на каждом этапе по оптимальной цене без посредников.` |

## 用词黑名单

以下词在 B2B 茶行业俄语中要么是英文借词、要么是直译，换掉：

| 避免 | 替换为 |
|------|--------|
| `кастомизация` | `изготовление под заказ` |
| `вкусовой профиль` | `вкус` / `вкусовые особенности` |
| `целевая аудитория` | `ваши клиенты` / `ваш рынок` |
| `мелкосерийный купаж` | `смесь от 20 кг` / `купаж малой партией` |
| `реплика`（指茶） | `возрождённый рецепт` |
| `вынослив к заварке` | `выдерживает много заварок` |
| `послевкусие`（中性，不是阳性） | `долгое сладкое послевкусие`（搭配中性形容词） |

## 语法检查清单

每次新增俄语内容，逐条过：

- [ ] 形容词性数格是否与名词一致（`долгое послевкусие` 不是 `долгий послевкусие`）
- [ ] 标点符号是否全部俄语（`?` `!` `.` `,` 不是 `？` `！` `。` `，`）
- [ ] 专有名词转写是否统一（`Мэнхай` 不是 `Menghai`、`Фанцунь` 不是 `Fangcun`）
- [ ] 数字单位是否俄语（`20 кг` 不是 `20kg`、`500 м²` 不是 `500m2`）

## 产品描述模板

产品描述每条不超过 4 句，按此结构写：

```
1. 品类+年份+厂家（1句，≤12词）
2. 核心卖点（1句，≤10词）
3. 口感特征（1句，≤10词）
4. B2B 适用场景（1句，≤8词）
```

示例：

```
Шу пуэр кирпич 2013 года, фабрика Юнфа.
Гушу сырьё из Баньчжан, сухое хранение 10+ лет.
Густой вкус с ореховыми нотами, долгое сладкое послевкусие.
Подходит для премиум-сегмента. Изготовление под заказ от 20 кг.
```

## 新增页面 / 产品的流程

1. 先写核心信息（产品名、年份、规格、卖点）
2. 拼成极短句（每句 ≤ 10 词）
3. 逐条过「语法检查清单」
4. 最后自问：把这句单独拿给俄罗斯人看，能看出是 AI 写的吗？能 → 再缩句
